CLI Platform Capabilities

Six unified commands designed for continuous DX developer workflows.

init

sf-lwc init

Configures default registry spec in sf-lwc.json for seamless local or team installation.

sf-lwc init
add

sf-lwc add <component>

Recursively installs component source files, merges Custom Labels, and updates sf-lwc.lock.json.

sf-lwc add modal
diff

sf-lwc diff <component>

Unified line-by-line diff comparing your locally customized code against the upstream registry.

sf-lwc diff modal
update

sf-lwc update

Inspects lockfile semver against upstream and safely upgrades component files and labels.

sf-lwc update --all
doctor

sf-lwc doctor

Comprehensive health check validating DX package root, registry connectivity, and lockfile physical file integrity.

sf-lwc doctor
pack

sf-lwc pack <component>

Automated metadata dependency tracing via Salesforce Tooling API across Apex, Labels, and Child LWCs.

sf-lwc pack myComponent -o myOrg
