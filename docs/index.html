      Built for Salesforce DX

      Designed around the realities of Salesforce DX development: real Apex dependencies, Custom Labels, and zero API quota friction.

      Zero REST Rate Limits

      Unauthenticated searches and component installs stream directly from GitHub Codeload tarballs and parse in-memory. api.github.com is never touched, preserving 100% of your 60 req/hr IP quota.

      Interactive Terminal UI

      Run sf-lwc add <source> without specifying components to open an interactive fuzzy multi-select selector powered by @clack/prompts with live previews.

      Full-Stack Metadata Bundling

      Doesn't stop at JavaScript and templates. Resolves and packages Apex controllers, unit test classes, and merges <labels> directly into CustomLabels.labels-meta.xml.

      Clean Sidecar Specification

      Component metadata lives in clean .sf-lwc/<name>.json sidecars. Enforces strict path traversal validation, lockfile ownership, and recursion depth protection.

      CLI commands

      Eight commands cover the whole lifecycle: initialize, install, discover, compare, update, remove, inspect, and package.

      sf-lwc init

      Writes the default registry spec and workspace settings to sf-lwc.json so team installs run consistently.

      $sf-lwc init

      sf-lwc add [source] [component...]

      Installs components and resolves sub-dependencies (child LWCs, Apex controllers, labels), updating sf-lwc.lock.json. Omit component names to launch interactive multi-select.

      $sf-lwc add svierk/awesome-lwc-collection

      sf-lwc list [source]

      Lists available components from a remote GitHub repository or local SFDX project without touching GitHub REST API quota. (Alias: ls)

      $sf-lwc list

      sf-lwc diff <component>

      Displays a unified, line-by-line colored diff between your local customized copy and the upstream registry version.

      $sf-lwc diff dataTable

      sf-lwc update [component...]

      Compares lockfile versions with upstream registry, then safely upgrades component files and Custom Labels (use --all to upgrade all).

      $sf-lwc update --all

      sf-lwc remove <component...>

      Safely removes an installed component and its files, checking dependency trees to prevent breaking dependent components (override with --force). (Alias: rm)

      $sf-lwc remove dataTable

      sf-lwc doctor

      Checks SFDX project root, configuration, registry reachability, lockfile integrity, and verifies that every tracked file exists on disk.

      $sf-lwc doctor

      sf-lwc pack <component>

      Inspects metadata dependencies through the Salesforce Tooling API across Apex, Labels, and child LWCs, exporting into clean .sf-lwc/ sidecars. (Alias: export)

      $sf-lwc pack myComponent -o myOrg
