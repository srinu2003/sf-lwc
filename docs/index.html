Component Registry

Salesforce DX Distribution Platform

Own your UI components. Zero runtime lock-in.

sf-lwc is the shadcn/ui for Salesforce Lightning Web Components. Copy clean, SLDS-accessible source code directly into your Salesforce DX project with automated dependency discovery.

Quickstart Installation
npx sf-lwc add modal

CLI Platform Capabilities

init

sf-lwc init

Configures sf-lwc.json in your DX project with your preferred GitHub or local component registry.

sf-lwc init --from owner/repo@main
add

sf-lwc add <component>

Recursively installs components, auto-merges Custom Labels into CustomLabels.labels-meta.xml, and records lockfile tracking.

sf-lwc add modal data-table
diff

sf-lwc diff <component>

Unified line-by-line diff comparing your locally customized components against upstream registry versions.

sf-lwc diff modal
update

sf-lwc update

Inspects sf-lwc.lock.json and safely upgrades installed components with custom label synchronization.

sf-lwc update --all
doctor

sf-lwc doctor

Health check auditing sfdx-project.json, default package directories, registry connectivity, and lockfile file integrity.

sf-lwc doctor
pack

sf-lwc pack <component>

Automated dependency tracing via Salesforce Tooling API across Apex, Child LWCs, Labels, and Decomposed Custom Objects.

sf-lwc pack myComponent -o myOrg
