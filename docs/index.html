      CLI commands

      Six commands cover the whole lifecycle: set up, install, compare, update, check, and trace dependencies.

      sf-lwc init

      Writes the default registry spec to sf-lwc.json so local and team installs work the same way.

      $sf-lwc init

      sf-lwc add <component>

      Installs a component and its dependencies, merges Custom Labels, and updates sf-lwc.lock.json.

      $sf-lwc add modal

      sf-lwc diff <component>

      Shows a unified, line-by-line diff between your customized copy and the upstream registry.

      $sf-lwc diff modal

      sf-lwc update

      Compares lockfile versions with the registry, then upgrades component files and labels safely.

      $sf-lwc update --all

      sf-lwc doctor

      Checks the DX package root, registry connectivity, and that every file in the lockfile exists on disk.

      $sf-lwc doctor

      sf-lwc pack <component>

      Traces metadata dependencies through the Salesforce Tooling API across Apex, Labels, and child LWCs.

      $sf-lwc pack myComponent -o myOrg
